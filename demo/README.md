# Demo Video

## Requirements (Section 7)

- [ ] Single continuous recording: **8–12 minutes**
- [ ] Real Android device (not emulator)
- [ ] MP4, **1080p minimum**, max **500 MB**
- [ ] Voiceover or on-screen captions required

## Content to show

1. App launch  
2. Athlete registration  
3. **≥4 tests** end-to-end (guidance → recording → AI measurement → result)  
4. Report card generation and PDF export  
5. **Offline demo:** airplane mode → 2 tests offline → report → reconnect → sync  

## File naming

```
TeamName_Demo_v1.0.mp4
```

If file exceeds 500 MB, add `DOWNLOAD_LINK.txt` with Google Drive / OneDrive URL (downloadable, not streaming-only).
