# Data Protection Compliance

## Required artifacts (Section 9)

| File | Description | Status |
|------|-------------|--------|
| `DATA_PROTECTION_DECLARATION.pdf` | Signed by all team members | [ ] |
| `consent_forms/` | Anonymised consent copies (names redacted) | [ ] |
| `DATA_INVENTORY.md` | Subjects recorded, storage, deletion plan | [ ] |

## Declaration must state

- (a) No athlete video uploaded to commercial cloud during dev/testing  
- (b) All video on hardware under team's physical control  
- (c) Informed consent from all validation subjects  
- (d) Parental/guardian consent for subjects under 18  
- (e) Data deleted or handed to organisers within 30 days of hackathon end  

If no footage was collected during prototyping, state explicitly in the declaration.
